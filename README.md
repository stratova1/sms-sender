# 📱 간편 대량 문자 발송기 (Simple SMS Sender)

스마트폰에서 엑셀(`devices.xlsx`) 또는 CSV 파일을 불러와 원클릭으로 대량 문자를 자동 발송하는 안드로이드 전용 앱입니다.

---

## 🌟 주요 특징 (스마트폰 조작이 서툰 분을 위한 설계)

1. **초간단 3단계 UI**:
   - [1. 엑셀 파일 선택] 버튼 터치
   - 대상 인원 및 메시지 확인
   - [2. 문자 발송 시작] 버튼 터치
2. **화면이 꺼져도 계속 발송**:
   - 상단바 알림(포그라운드 서비스) 및 백그라운드 전송 유지
3. **통신망 및 기기 보호 기능**:
   - 건당 2초 간격 분산 발송
   - 100건 발송 시 자동으로 30초 휴식 후 재개
4. **엑셀 & CSV 모두 지원**:
   - `.xlsx`와 `.csv` 형식 자동 감지 및 파싱

---

## 🚀 PC에 아무것도 안 깔고 폰에 앱(APK) 설치하는 방법 (3단계)

GitHub의 무료 자동 빌드(Actions)를 이용하여 2분 만에 스마트폰 설치 파일(`app-debug.apk`)을 받으실 수 있습니다.

### 1단계: GitHub에 저장소 만들기
1. [GitHub](https://github.com)에 로그인합니다.
2. 우측 상단의 **[+]** 버튼을 누르고 **[New repository]**를 클릭합니다.
3. 저장소 이름(Repository name)에 `sms-sender`라고 적고, **[Create repository]**를 누릅니다.

### 2단계: 파일 업로드하기
1. 새로 만들어진 페이지에서 **`uploading an existing file`** 링크를 클릭합니다.
2. 이 폴더(`sms_sender_app`) 안의 파일들을 마우스로 드래그해서 모두 끌어다 놓습니다.
   (또는 `sms_sender_app.zip` 압축을 해제한 내용물들을 업로드합니다.)
3. 아래의 초록색 **[Commit changes]** 버튼을 누릅니다.

### 3단계: 스마트폰으로 APK 다운로드 및 설치
1. 상단 메뉴의 **[Actions]** 탭을 클릭하면 `Build and Release APK` 작업이 자동으로 돌아갑니다 (약 1~2분 소요, 초록색 체크표시 확인).
2. 저장소 우측의 **[Releases]** 섹션(또는 Actions 결과 페이지의 Artifacts)을 클릭합니다.
3. 스마트폰 인터넷 브라우저로 접속하여 **`app-debug.apk`**를 터치해 다운로드합니다.
4. 다운로드 완료 후 파일을 터치하여 **[설치]**를 진행합니다.
   *(※ "출처를 알 수 없는 앱" 경고가 뜨면 '설치 허용' 또는 '무시하고 설치'를 눌러주시면 됩니다.)*

---

## 📱 앱 사용 방법
1. 앱을 실행하고 **[권한 허용]**을 눌러 SMS 전송 권한을 줍니다.
2. **[1. 엑셀 파일 선택]**을 눌러 카카오톡이나 다운로드 폴더의 `devices.xlsx`를 선택합니다.
3. 대상 인원수와 메시지 미리보기를 확인합니다.
4. **[2. 문자 발송 시작]**을 누르면 자동으로 순차 발송됩니다!
